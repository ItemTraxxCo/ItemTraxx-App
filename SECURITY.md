# Security Policy

To report a vulnerability, follow the [ItemTraxx Vulnerability Disclosure Policy](docs/legal/vulnerability-disclosure-policy.md), which includes written safe-harbor authorization for good-faith research.

- **Email:** security@itemtraxx.com
- **Web form:** [itemtraxx.com/report-security-issue](https://itemtraxx.com/report-security-issue)
- **Machine-readable contact:** [`/.well-known/security.txt`](https://itemtraxx.com/.well-known/security.txt)

Please do not open public GitHub issues for security reports, and do not access, keep, or share real student or customer data. If this file differs from the published policy page, the published page controls.
